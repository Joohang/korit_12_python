# Coffee_Machine 클래스 생성
물: 100ml
우유: 50ml
커피: 76g
돈: $2.5
는 정적 변수로 선언 -> 이유 : 프로그램이 실행되고 꺼지고 다시 시작해도 저장되야 해서?!

커피 종류별 금액과 필요한 자원은 정적변수와 같은 변수명을 key값으로 dictionary 하면 될듯

필요한 메서드 : 커피 머신을 돌리는 전체 로직을 기능에 따라 메서드화

1. off 기능

2. 보고서 생성 (report 입력시) 정적 변수 출력

3. 무엇을 드시겠습니까 출력 기능

4. 사용자가 입력한 커피를 만들 수 있는지 자원을 확인하는 기능 - 자원이 부족할 경우 'xx 부족' 출력

5. 선택한 커피를 만들 자원이 충분할 경우 - 삽입된 동전 계산 기능

6. 동전이 충분한 경우 - 잔돈이 필요한 경우 잔돈 계산 
    동전이 부족한 경우 - 금액이 부족합니다. 금액 반환

7. 커피 머신 작동 - 자원에서 커피를 만든 재료만큼 차감, 수익만큼 동전 증가

8. 모든 자원 연산 후 사용자에게 알려주는 기능

전체 로직은 while문에서 off = false 일때 계속 반복하는 구조

1번 메서드는 off = true로 하면 되지 않을까

while 문 첫 번째 커피 선택 출력 기능

if 문으로 현재 커피머신의 자원량과 선택 커피의 사용 자원량을 key 값으로 value 계산

자원량이 충분한 경우 또 if 투입한 동전 계산
